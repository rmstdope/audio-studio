Option B — on an image page the arrows stay with the takes

On an image page, ← and → keep stepping the takes from anywhere on the page, exactly as today. The ‹ › buttons still go to the previous or next image; only the arrow keys do not. Every other page is unchanged. Cost: the image page is the one page where the arrows do not step items, so its hover words leave out the key.
