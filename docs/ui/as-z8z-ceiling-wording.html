The 300% line names what is still too quiet — agreed (as-z8z)

When making the whole scene louder stops at the 300% limit, the sentence that follows names what would still be too quiet. A scene with no states says “The scene would…”. A scene with states names each state still short, with its own figure, whether one, some or all are short. The rest of the line is as agreed in as-gdf.2. Changed words are highlighted.
