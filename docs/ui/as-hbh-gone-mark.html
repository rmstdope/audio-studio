the mark drops under the menu, whole

When the mark does not fit beside the state’s menu, it moves as a whole onto its own line under the menu — the same way “every 4–9 s” already drops under its menu. It is never broken and never cut; the state name is never cut either. The coins row is one line taller than a row without the mark, the same height as the drip-echo row.
