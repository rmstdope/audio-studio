Choosing the music model — agreed

One default music model for the project, a fourth row in Setup's Models panel, saved in the project file. A track's Takes panel has a menu beside More takes (and beside Make 2 takes), starting on Setup's model each time the page opens; every take names the model that made it. Every model is listed; one this computer doesn't have is marked and can't make takes here. Try again remakes a failed take with the model it was asked with. Changing the default leaves chosen tracks chosen. The list of models is an example: whoever builds this settles it from what the music generator offers, naming each in the same plain style.
