Where What’s there marks each named area

In the Named areas panel, each placed box has a point: where RetroQuest’s What’s there marks the thing. It starts at the centre. Drag it anywhere inside the box; it is saved as soon as it is let go.

A placed box, point never moved

The selected box shows the full-size point at its centre; the other placed boxes show a small dot. No “Centre the point” button: there is nothing to undo.
