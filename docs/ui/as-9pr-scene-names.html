When an effect name that does not fit

The name is cut where the room runs out and ends in “…”. Two names that differ only at the end look the same until you hover.
Hovering the pointer over a cut name shows the whole name. A screen reader always reads the whole name. A short name such as “wind-howl” is never cut.
