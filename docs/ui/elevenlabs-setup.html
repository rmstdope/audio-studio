ElevenLabs on Setup

Two optional rows at the end of Setup's checklist, as Stable Audio's is: the key, and the account. The account is asked only when there is a key. Each state is drawn below; the words are those that ship.

1 — No key (every project until one is set)

  • Not set up
    ElevenLabs API keyOptional: for ElevenLabs voices and music. No ELEVENLABS_API_KEY in the environment or in .env.Put ELEVENLABS_API_KEY=... in .env (from elevenlabs.io, Developers, API keys), or export it.
  • Not used
    ElevenLabsNot asked: there is no key.

With usage beyond the plan allowed, the first note reads "Up to 5,000 more credits may be used beyond them, billed in dollars." or "Usage beyond them is billed in dollars, without limit."
