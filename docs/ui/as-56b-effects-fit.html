Option A — a long name wraps inside its menu

Nothing is cut and nothing scrolls. A state or trigger name too long for its column wraps onto a second line inside its own menu, breaking at a hyphen where it can (“drowned-and-” / “forgotten”). That row grows by one line, like a row whose “every 4–9 s” has dropped. Short names look exactly as today.
