Keyboard. Everything is reachable with Tab in reading order: the scene list (arrow keys move through it), the heading’s buttons, Music, each effect row, Add, then the play bar. The play button is Space/Enter like any button; no page-wide shortcut, since Space also moves sliders. Sliders: arrows ±5%. After Save, focus stays on the Save button; after removing an effect (✕), focus goes to the next row’s ✕, or to Add when it was the last.
What persists. The open scene is in the address, so a reload or the back button returns to it. Unsaved changes do not survive a reload (the browser asks first). A Refresh from the game keeps everything you set; new scenes, states and triggers appear, removed ones are marked gone. The play bar’s state and whether it is playing reset when you open another scene.
